Human page

Sell to humans. Be readable to AI.

This is a starter template that pairs a normal landing page with an AI-readable page (/ai/), plus llms.txt, sitemap.xml, and clean linking.

Open AI-readable version → Read the full guide on Gumroad → Author GitHub →

What you get

  • Human-first landing page (/)
  • AI-readable landing page (/ai/) with explicit structure
  • llms.txt that points agents to the right URL
  • rel=alternate + canonical links + sitemap

How to use

  1. Fork this repo
  2. Edit copy on index.html and ai/index.html
  3. Enable GitHub Pages
  4. Share your GitHub Pages URL

Tip: keep both pages consistent in meaning; only change presentation.

AI-readable is not “redirecting bots”. It’s providing a reliable alternate representation that agents can parse.
