# AI-Readable Commerce Starter

A tiny reference implementation:
- Human-first landing page: `/`
- AI-readable landing page: `/ai/`
- Agent routing hint: `/llms.txt`
- Discovery: `/sitemap.xml`

## Demo
Enable GitHub Pages and your demo will be available at:
`https://chanwoo522.github.io/ai-readable-commerce-starter/`

## Why this exists
Search is becoming *agent-mediated*. This template provides a clean “alternate representation” that agents can parse reliably — without cloaking or fragile bot redirects.

## Quick start (5 minutes)
1) Fork this repo  
2) Edit:
   - `index.html` (human page)
   - `ai/index.html` (AI page)
3) Replace `https://chanwoo522.github.io/ai-readable-commerce-starter/` in:
   - `index.html`, `ai/index.html`, `llms.txt`, `sitemap.xml`, `robots.txt`
4) GitHub Pages:
   - Settings → Pages → Deploy from branch → `main` / root  
5) Share your Pages URL
